# AI-codes

Jogos e experimentos feitos com IA.

- [Racha 3D](https://fernandosouz.github.io/AI-codes/racha-3d/): corrida 3D para celular. Dá pra correr contra o computador ou desafiar outra pessoa pelo QR code, sem login.
- [Rua Morta](https://fernandosouz.github.io/AI-codes/rua-morta/): tiro em primeira pessoa contra zumbis. Você anda sozinho pela rua, mira mexendo o celular (giroscópio) e atira tocando na tela.
